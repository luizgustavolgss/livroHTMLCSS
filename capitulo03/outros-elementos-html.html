Guia de Elementos "in-line"

Elementos <b> e <strong>

Elemento <b>
Serve apenas para estilização visual em negrito;
Elemento <strong>
Além do anterior, este serve também para dar forte ênfase sendo útil por exemplo no uso de leitores de tela;

Elementos <i> e <em>

Elemento <i>
Serve apenas para estilização visual em itálico;
Elemento <em>
Além do anterior serve também para ênfase com uso similar ao conjunto de elementos anterior;

Elemento <small>

Serve para marcar pequenos trechos de texto relacionados com o conteúdo do texto onde foram marcados renderizando-os em tamanho menor que o texto em que foi marcado.

muito útil para notas como advertências e rodapé

Elemento <code>

Este elemento serve para marcar código de computador ou então qualquer string que possa ser reconhecida pelo computador.


  • Elementos HTML como div
  • Códigos como const exist = (val) => val != null;

Elemento <hr>

Representa uma quebra temática entre conteúdos relacionados, sendo renderizada normalmente como uma linha horizontal.

Elemento <span>

o elemento span assim como a <div> é um elemento sem valor semântico, e acaba sendo muito similar com a diferença de ser in-line. Igualmente seu uso se torna expressivo com CSS para estilização.

Guia de Elementos "block-level"

Elemento <header>

Serve na marcação de conteúdo introdutório, aqui normalmente temos tags como h1-h6, auxilia na navegação e contém logotipos

Elemento <nav>

Nav é um elemento que serve como um menu de navegação principal, com pequenos grupos de links relacionados ao conteúdo da página ou site, mas dentro do article deve estar relacionado ao conteúdo deste.
para usar os links com elementos da página é necessário o uso de IDs

Elemento <aside>

serve para referenciar elementos relacionados entre si, geralmente usados para marcar barras laterais de conteúdos ou elementos relacionados porém separados visualmente.

caso dentro de um <article> deve referenciar-lo, caso fora deve referenciar o conteúdo da página ou site em si.

Elemento <main>

Aqui é onde fica todo o conteúdo principal da página, nela não devem conter o <header> principal.

Elemento <div>

Dentro da div

O elemento div é um elemento sem valor semântico, ele pode conter diversos outros elementos inclusive outros <div>, seu uso se torna mais evidente com CSS para estilização.

Elemento <article>

Elemento que determina que o conteúdo pode ser interpretado e exportado individualmente de forma a ainda manter o entendimento completo do que ele carrega, sendo independente.

Elemento <section>

Representa uma seção temática do documento, normalmente contendo título e agrupando conteúdo relacionado.

Elemento <footer>

o footer é usado geralmente para conteúdos de rodapé como quem escreveu o conteúdo, links relacionados, informações sobre o site ou mesmo sobre direitos autorais.
