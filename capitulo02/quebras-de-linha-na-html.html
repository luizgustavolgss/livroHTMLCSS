Elementos podem ou não causar quebra de linha em html, este são conhecidos como "elementos nível de bloco.", como por exemplo o próprio "p", já aqueles que não o fazem são chamados de "elementos inline", como o de itálico ou negrito.
Observe inclusive que espaços ou quebras de linhas dentro dos elementos não renderizam quebra de linha para o usuário como pode ver.
Para isso usamos justamente o "br" que renderiza uma quebra de linha dentro de outro elemento.
